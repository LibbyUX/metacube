# Documentation

## Current handoff

The canonical guide for the supported component is the [`cifar-cube` handoff README](../packages/cifar-cube/README.md). It includes the integration contract, accessibility behavior, theming API, validation behavior, build format, and remaining verification work.

The former `<cifar-metacube>` prototype and its API have been retired. Use `<cifar-cube>` from `packages/cifar-cube`.

## Legacy metacube reference

The [configuration reference](config.md) documents the inherited CSV/YAML metacube playground and its visualization options. It is retained for the demo and is not part of the `cifar-cube` component contract.

The Python and R packages are also inherited reference implementations. Their setup and usage remain documented in [`python-pkg/README.md`](../python-pkg/README.md) and [`r-pkg/README.md`](../r-pkg/README.md).
